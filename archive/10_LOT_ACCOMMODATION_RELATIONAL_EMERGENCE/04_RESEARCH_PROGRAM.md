# Research Program

## Core Hypothesis C0 — S∞ ↔ B∞ relational accommodation
A localized relational structure S∞ and an extended relational structure B∞ mutually constrain one another. Candidate loop: S_n → B_n → S_(n+1) → B_(n+1) → ... . Candidate response chain: S∞ → δB∞ → δK → collective response.
**Status:** HYPOTHESIS / OPEN.

## Branch 1 — B1: Accommodation / Dynamics
Can finite, stable dynamics be defined for accommodation? Candidate M x¨ + Γx˙ + Kx = -J. Test stability, finite response, energy accounting, propagation and nonlinear response. **Status:** TOY / OPEN.

## Branch 2 — B2: Relational Network / Propagation
Can B∞ be a network whose relational structure determines propagation? Candidate weighted Laplacian L_K. Test finite-N behavior, large-N scaling, speed, locality and topology. **Status:** TOY / OPEN.

## Branch 3 — B3: Effective Distance / Geometry
Can relational changes alter effective distances and eventually produce a consistent metric? Candidate K → ℓ_ij → d_eff → g_eff. Test metric consistency, isotropy, locality, smooth continuum limit and observer consistency. **Status:** TOY / HYPOTHESIS / OPEN.

## Branch 4 — B4: Quantum Modes
Can the same relational structure produce a consistent quantum description? Candidate L_Ku_n=λ_nu_n plus a valid quantization. Test canonical structure, commutators, evolution, interference and known limits. **Status:** HYPOTHESIS / OPEN.

## Branch 5 — B5: Emergent Gravity / GR
Can large-scale relational response produce an effective Lorentzian metric whose dynamics reproduce GR limits? Required path: B∞ → g_eff → curvature → gravitational dynamics. Targets include Newtonian limit, light deflection, redshift, geodesics, gravitational waves and Einstein-equation recovery. **Status:** OPEN / HIGH-BAR.

## Branch 6 — B6: Criticality / Instability
Can finite accommodation capacity produce controlled critical transitions? Candidate det L_K → 0 or related criterion. Test bifurcations, soft modes, nonlinear saturation and energy behavior. **Status:** OPEN.

## Branch 7 — B7: Thermodynamics
Can entropy, equilibrium and irreversibility emerge from coarse-graining? **Status:** DEFERRED / OPEN.

## Branch 8 — B8: Electromagnetism / Charge / Current
Does the relational theory naturally contain conserved charge-like or gauge-like structures? No identification without derivation. **Status:** DEFERRED / OPEN.

## Branch 9 — B9: Matter / Particle Excitations
