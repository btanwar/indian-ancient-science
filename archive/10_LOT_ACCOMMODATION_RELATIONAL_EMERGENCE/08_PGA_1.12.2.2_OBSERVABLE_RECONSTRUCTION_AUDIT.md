But the result is a **partial order**, not a unique total sequence.

Therefore:

**causal order ≠ global time**

This is not a defect. Causally disconnected events need not have a fundamental ordering.

## 6. Emergent-c audit

The earlier research did investigate finite propagation speed and emergent c. This changes the coarse table used previously.

### 6.1 Finite causal propagation

Discrete relational/lattice models produced finite propagation fronts, with representative scale

c_D = a sqrt(κ/m)

and dispersion

ω² = (4κ/m) sin²(ka/2).

In the long-wavelength limit:

ω ≈ c_D k.

**Result: 🟢 finite-speed propagation exists in toy models.**

But c_D depends on model parameters. It is not yet a derived universal physical c.

### 6.2 Fixed-lattice test

The group velocity behaves as

v_g = c_D cos(ka/2).

The lattice contains a preferred microscopic frame.

Thus:

- finite causal cone: survives;
- IR linearity: survives approximately;
- exact Lorentz invariance: not derived.

### 6.3 Random relational network test

A random 256-node 4-regular network showed reachability saturation approximately as:

1 → 5 → 17 → 51 → 120 → 219 → 255 → 256.

This produced small-world saturation rather than a geometric causal cone.

**Result: 🔴 generic random relational connectivity does not automatically produce the required causal structure.**

### 6.4 Ordered-local dynamics

An ordered local update model produced a finite front:

r_max = n ℓ* = (ℓ*/τ*) t = c* t,

with

c* = ℓ*/τ*.

**Result: 🟡 finite causal cone survives in a local ordered model.**

However the microscopic frame remains preferred.

Therefore:

finite causal cone ≠ Lorentz invariance.

### 6.5 Sampling frequency is not c

The dimensional audit explicitly rejected:

f_sample = c.

Sampling frequency has units 1/s; c has units m/s.

The refined hypothesis was:

c* = emergent relational distance / emergent relational duration.

That is a better hypothesis, but both numerator and denominator must be derived from the same substrate.

## 7. Lorentz audit

The historical work identified three stronger requirements:

A. Isotropy:

v(n-hat) = v

B. Universal low-energy propagation speed for the relevant modes.

C. Observer independence: different observers reconstruct the same null/causal structure.

All three are required for evidence of an emergent Lorentz sector.

The existing fixed-lattice and local-dynamics tests do not satisfy all three.

**Status: 🔴 Lorentz symmetry not derived.**

## 8. Lorentz reconstruction versus Lorentz derivation

A separate mathematical construction showed that if the same causal structure is reconstructed by different observers, coordinate transformations preserving

c²t² − x²

take the Lorentz form.

This establishes:

same causal structure → different coordinate reconstructions → Lorentz transformations.

But the causal structure itself has not yet been derived from the S∞ ↔ B∞ microscopic substrate.

Therefore this is a reconstruction result, not a microscopic derivation of Lorentz symmetry.
