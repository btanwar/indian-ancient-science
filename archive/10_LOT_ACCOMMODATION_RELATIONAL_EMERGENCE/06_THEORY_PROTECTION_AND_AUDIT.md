# Theory Protection and Audit

## Purpose
Protect the S∞ ↔ B∞ research from premature unification claims while allowing the framework to be enriched.

## 1. Derive before identify
Never write `K = gravity`, `mode = particle`, `antisymmetry = time`, `coupling = charge`, `irreversibility = entropy`, or `network = spacetime` without derivation and benchmark support.

## 2. Evidence ladder
`ANALOGY → TOY → HYPOTHESIS → DERIVATION → KNOWN-LIMIT RECOVERY → PREDICTION`.
Do not promote a result by language alone.

## 3. Failure taxonomy
F1 analogy failure; F2 mechanism failure; F3 branch failure; F4 core-framework failure. F1–F3 should not automatically kill C0.

## 4. Kill tests
Actively search for mathematical inconsistency, unstable/unbounded energy, instantaneous influence, causality violation, conservation failure, continuum nonconvergence, coordinate-dependent physical predictions, failure to recover established limits, hidden insertion of target physics, and arbitrary parameter proliferation.

## 5. Anti-overfitting
If a model is changed to reproduce a known result, record what changed, why, whether it was independently motivated, and what new prediction remains.

## 6. Preserve failures
Record `hypothesis → experiment → result → interpretation → what is ruled out → what remains open`. Never delete a failed branch because a later mechanism looks better.

## 7. Theory survival principle
The strongest version is the smallest core that is mathematically coherent, makes nontrivial predictions, recovers known physics where required, and survives attempts to falsify it.

## Protected core
`S∞ ↔ B∞` is currently protected only as a hypothesis that localized relational structure and extended relational organization may mutually constrain each other, with the interaction potentially producing collective response. Everything beyond that remains to be derived.
