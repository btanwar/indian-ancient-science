# Archive

This directory preserves source documents and superseded organization moved during the repository
cleanup. Files here remain part of the research record and retain their original branch numbers,
analogy IDs, line-of-thought IDs, requirement IDs, and PGA identifiers.

- `Analogies/`, `Line-Of-Thoughts/`, and `Requirements/` are the original indexed collections.
- `Research/` contains the original runbooks and research-level audits.
- `10_LOT_ACCOMMODATION_RELATIONAL_EMERGENCE/` and `11_EPR_BELL_CHANDAS/` preserve numbered branch
  source documents.
- `RESEARCH_GRAPH/` preserves the former graph view and state files.

The canonical navigation files are at the repository root. Archiving a document does not mean its
scientific content was rejected.
