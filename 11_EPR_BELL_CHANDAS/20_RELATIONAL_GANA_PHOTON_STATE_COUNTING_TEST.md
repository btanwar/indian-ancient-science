The relevant structural lesson is:

→ allowed states

→ macroscopic statistical law.

This does NOT establish that Piṅgala/Yamātārājabhānasalagam historically supplied Bose's method, nor that the two systems are physically identical.

## 4. Minimal counting experiment

Let g be the number of available relational modes and N the number of indistinguishable relational quanta/occupants.

The number of bosonic occupation configurations is

W_B(g,N) = C(N+g-1,N).

This is the same combinatorial structure used in Bose-type occupation counting.

For example, if g=3 and N=2,

W_B = C(4,2)=6.

This establishes that occupation counting can be generated from combinatorics alone.

Status: 🟢 mathematical counting structure.

## 5. Does counting determine photon energy?

No.

The combinatorial quantity W_B is dimensionless.

It can determine multiplicity/statistical weights, but it cannot by itself determine an energy in joules.

Therefore

counting → energy

requires an independently derived energy-per-mode relation.

Status: 🔴 not derived.
