# Line of Thoughts

A **line of thought** is a named research direction built by combining one or more analogies (like
beads strung on a thread to form a mala) into a coherent question worth investigating in modern
science or technology.

Copy [`templates/LINE_OF_THOUGHT.md`](../templates/LINE_OF_THOUGHT.md) to create a new line of thought, name it `L###_short-name.md`, and add a row to
the index table below.

## Rules

- A line of thought must state a clear **goal** and a clear **domain** (what field of science/
  technology it targets).
- It must list every analogy it draws from (link to `Analogies/`).
- It must link to its `Requirements/R###_short-name.md` and its `Research/L###_short-name/` folder
  once research begins.
- Status must be kept current using the shared status labels (see root `README.md`).
- Do not merge unrelated lines of thought just because they share an analogy; keep them separate
  and cross-link instead.
